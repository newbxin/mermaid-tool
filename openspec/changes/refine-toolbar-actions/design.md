## 上下文

预览面板当前已经包含多个高频动作：缩放步长输入、缩放百分比输入、缩放按钮、最大化、SVG 导出和 PNG 导出。随着控制项增多，纯文字按钮和并列导出按钮会让工具栏变宽，也让动作含义依赖文案排布。

本变更聚焦工具栏动作的可用性和一致性，不重新设计 Mermaid 渲染流程，也不改变 `configurable-preview-zoom` 已定义的缩放边界、步长校验和 `Shift` + 滚轮行为。

## 目标 / 非目标

**目标：**
- 使用 `@radix-ui/react-tooltip` 为图标按钮提供可访问的悬停/聚焦说明。
- 使用 `@radix-ui/react-select` 承载 SVG/PNG 导出格式选择。
- 使用 `lucide-react` 为常见工具栏动作提供一致图标。
- 最大化按钮在进入最大化和退出最大化时显示不同图标。
- 缩放输入错误提示使用提示组件呈现，并继续通过 `aria-invalid`、`aria-describedby` 或等效属性关联到对应输入。
- 下载流程变为先选择 `SVG` 或 `PNG`，再点击下载按钮。
- 保留现有本地导出、DOMPurify 清理和缩放/拖拽行为。

**非目标：**
- 不新增导出格式。
- 不持久化用户选择的导出格式。
- 不更改 Mermaid 代码编辑器能力。
- 不引入全局设置页或新的布局架构。
- 不改变缩放合法范围、步长合法性规则或错误文案语义。

## 设计

新增依赖：

```text
@radix-ui/react-tooltip
@radix-ui/react-select
lucide-react
```

工具栏按钮采用图标按钮，图标来自 `lucide-react`。每个不显示文字的按钮都包裹 Tooltip，并在 `aria-label` 中提供同等动作名称，确保鼠标、键盘和辅助技术用户都能理解按钮用途。中间 Convert 按钮保留原有窄栏位置和点击面积，但将竖排文字替换为转换方向图标；渲染中状态使用加载图标。

最大化图标按状态切换：

```text
未最大化：Maximize2 / PanelTopOpen 等进入最大化含义图标
已最大化：Minimize2 / PanelTopClose 等退出最大化含义图标
```

实际图标名称可结合 `lucide-react` 可用图标与现有视觉尺寸选择，但同一类动作应在 Editor 和 Preview 中保持一致。

导出区域从两个按钮改为组合控件：

```text
[格式 Select: SVG | PNG] [Download 图标按钮]
```

Select 的当前值保存在预览组件本地状态中，默认值建议为 `SVG`，因为 SVG 是当前 Mermaid 渲染结果的原生格式。点击下载按钮时，根据当前格式调用既有 `downloadSvg` 或 `downloadPng` 逻辑。格式切换本身不应触发下载。

缩放输入错误提示改用提示组件，建议抽出轻量的局部错误提示渲染结构，复用现有校验状态：

```text
输入框 aria-invalid=true
输入框 aria-describedby=<error-id>
提示内容 id=<error-id>
提示内容 role=alert 或 aria-live=polite
```

提示组件可以基于 Radix Tooltip 的呈现能力，也可以作为同风格的内联提示气泡实现；关键要求是错误内容在视觉上像提示组件，并且 DOM 中仍保留可被辅助技术引用的错误文本。

## 决策

### 1. 选择 Radix 而不是自制 Select/Tooltip

Radix 组件提供键盘交互、焦点管理和 ARIA 基础语义，适合工具栏这类紧凑控制区域。项目只需补充样式以匹配现有主题。

### 2. 导出动作用单一下载按钮

格式选择和执行下载分离后，工具栏宽度更稳定，后续如果增加格式也不需要继续增加并列按钮。当前变更不新增格式，只重组已有 SVG/PNG 能力。

### 3. 保留输入错误的无障碍关联

错误提示换成提示组件后，不能只依赖悬停可见状态。错误文本必须在 DOM 中拥有稳定 `id`，并由对应输入通过 `aria-describedby` 引用。

## 风险与取舍

| 风险 | 缓解措施 |
|------|------------|
| 新增依赖增加打包体积 | 只引入需要的 Radix 包和 lucide 图标，避免整包图标注册 |
| 图标按钮含义不如文字直观 | 每个图标按钮提供 Tooltip 和 `aria-label` |
| Select 样式可能与现有主题不一致 | 使用 `tokens.css` 变量定义背景、边框、焦点和悬停状态 |
| 错误提示若只在悬停时出现会影响可访问性 | 错误状态下保持错误文本可被 `aria-describedby` 引用，并使用 `aria-live` 或 `role=alert` |
| 导出流程多一步选择可能影响老用户习惯 | 默认选择 SVG，并让下载按钮位置稳定，减少操作成本 |
